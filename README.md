# Agenda Isidora 3.0

Agenda personal con rutinas semanales, eventos, medicamentos y recordatorios.

## Abrir la aplicación

https://lc1733.github.io/Isidora/

La agenda guarda los datos localmente en el dispositivo. Para recibir avisos con el teléfono bloqueado, usa **Ajustes → Pasar todo al calendario**.
